## Sou de outra área da empresa

**Toda demanda entra pelo Planio.** Não abra issue aqui no GitHub e não peça direto para um dev — isso não é burocracia, é o que garante que seu pedido seja visto e priorizado em vez de se perder numa conversa.

**Planio:** https://softilux.planio.com

O que acontece depois: toda tarefa nova é avaliada na **triagem, no mesmo dia útil**. Você recebe uma de quatro respostas — entrou no backlog, falta informação, foi recusada (com justificativa) ou foi escalada. Nunca fica sem resposta.

Para o pedido andar rápido, inclua:

- **Objetivo** — o que você quer alcançar e por quê, em linguagem de negócio
- **Critério de aceite** — como saberemos que está pronto
- **Sistema** — em qual produto isso acontece
- **Anexos** — print, log, exemplo, layout

📖 [Ciclo da demanda](https://github.com/Softilux-Desenvolvimento-de-Sistemas/.github/blob/main/devs/workflow/demand-cycle.md)

### É urgente de verdade?

Urgência é: produção caiu, cliente parado, prazo legal. Nesse caso vai direto para o plantonista da sprint — mas a tarefa é criada no Planio **mesmo assim**.

Não é urgência: "o diretor perguntou", "é rapidinho", "só mudar uma coisinha".
